# Adaptive Music Lab

```sh
flutter pub get
flutter run -d macos
```

Use **Play**, **Pause**, **Restart track**, **Next track**, and **Stop and rewind**.
Adjust volume and cutoff during playback; turn off **Smooth controls** to compare
instant changes. Choose repeat and crossfade settings, then **Apply playlist
setup** to load them. **Open audio** replaces the list with your selected files.

The bar graphic is a decorative progress display, not a measured waveform.
The bundled 16-second loops are generated by `../tool/generate_demo_audio.py`.

For a native signal test (plays low-volume tones):

```sh
flutter test integration_test/audio_test.dart -d macos
```
