# Third-party dependencies

This project uses dependencies through Pub; their source is not vendored here.

- [flutter_soloud](https://pub.dev/packages/flutter_soloud): Dart plugin under MIT.
  Its native engine and bundled codec components carry their own notices; see
  [the project's license documentation](https://pub.dev/packages/flutter_soloud#license).
- [http](https://pub.dev/packages/http): BSD-3-Clause.
- [Flutter](https://github.com/flutter/flutter/blob/master/LICENSE): BSD-3-Clause.
- Example only: [file_selector](https://pub.dev/packages/file_selector), BSD-3-Clause.

Applications distributing native binaries must preserve the applicable dependency
notices. The demo WAV files are generated by `tool/generate_demo_audio.py` from
synthesized oscillators and deterministic noise, with no third-party samples.
They are covered by this repository's MIT license.
